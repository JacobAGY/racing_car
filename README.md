# 摇一摇赛车 · 50人现场版

扫码即玩，无需下载。观众摇手机加速，大屏实时展示比赛。

## 页面

- 手机端：`http://服务器IP:3000/` —— 输入昵称 → 授权摇一摇 → 加入 → 摇手机加速
- 大屏端：`http://服务器IP:3000/screen` —— 二维码 + 赛道 + 实时榜单 + 主持人控制台（开始/重赛/清人）

## 本地运行

```bash
npm install
npm start
```

手机和电脑连同一 WiFi，手机浏览器打开 `http://电脑IP:3000/` 即可联调。
大屏打开 `http://电脑IP:3000/screen`。

## 现场部署要点

1. 必须 HTTPS（否则 iOS 不给运动传感器权限），Nginx + Certbot 申请证书后反代 3000 端口。
2. iOS 需用户点击按钮时申请 `DeviceMotionEvent.requestPermission()`，本项目已在"加入"按钮中处理，务必引导用户点"允许"。
3. 一局 30 秒、赛道 1000 米，可用环境变量调参：`RACE_DURATION_SEC / TRACK_LENGTH / BASE_SPEED / SHAKE_FACTOR / MAX_PLAYERS`。
4. 无数据库、无 Redis，单进程内存存房间，重启即清空，2核4G 服务器带 50 人无压力。

## 玩法

主持人在大屏点"开始"→ 3-2-1 倒计时 → 观众疯狂摇手机（摇得越快速度条越高）→ 先到 1000 米或 30 秒跑最远者胜 → 大屏公布冠亚季军。
